================================================================================
  SECURE ATTENDANCE — Run on Android (Windows)
================================================================================

BEFORE YOU START (one-time on your PC):
  1. Install Flutter: https://docs.flutter.dev/get-started/install/windows
  2. Install Android Studio (Android SDK)
  3. Run in PowerShell:  flutter doctor --android-licenses   (accept all)

PHONE (REQUIRED — face will NOT work on PC emulator):
  Windows is only for BUILDING the app. The app runs on your ANDROID PHONE.
  1. Settings → Developer options → USB debugging ON
  2. Connect phone with USB cable
  3. On phone, tap Allow / Trust this computer
  4. CLOSE any Android emulator (Android Studio → Device Manager → stop emulator)
  5. Run:  flutter devices
     → You MUST see your phone name. If you see "emulator" or "sdk gphone", STOP
       the emulator and run flutter devices again.

IN THIS FOLDER (PowerShell or CMD):

  flutter clean
  flutter pub get
  flutter run

  → When asked, pick your PHONE (not emulator).
  → Or:  flutter run -d <device-id-from-flutter-devices>
  → First build can take 10–20 minutes. Wait until the app opens.

  Face error -101 = you used an emulator. Use a real phone only.
  Face: if KBY license fails (-2), the app automatically uses the built-in
  on-device face model (MobileFaceNet) — no KBY key needed for demo.
  Everyone must REGISTER FACE AGAIN after git pull if they registered before.

  Face error -2 dialog (old builds only) = wrong build or old app on phone:
     powershell -ExecutionPolicy Bypass -File scripts\windows\verify-face-signing.ps1
     adb uninstall com.attendance.attendance_app
     flutter clean && flutter pub get && flutter run
     (Needs android\team-debug.keystore from git — run git pull first.)

  If build asks for Android NDK 27: open Android Studio → SDK Manager → SDK Tools
  → check "NDK (Side by side)" version 27.0.12077973 → Apply.

TROUBLESHOOTING:
  - "flutter" not found → reinstall Flutter, open a NEW terminal
  - Lost connection / app keeps stopping → use a REAL phone, not x86 emulator
  - No device listed → install phone USB driver; try another cable
  - Face "activation -2" → delete android\key.properties if you created one, run again
